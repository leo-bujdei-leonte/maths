# Kernels of orbit homomorphisms for the Witt algebra

- `psi_kernel_check.py` — checks exactly (rational arithmetic) whether an element of U(W_{>=-1})
  lies in the kernel of Pham–Timmins' orbit homomorphism Psi_n.
- `kernel_psi1_positive_witt.tex` / `.pdf` — proof via the Conley–Goode method that
  ker(Psi_1 restricted to U(W_{>=1})) is generated by the differentiator Omega^(3)_{5,1}.

## Usage

```
python3 psi_kernel_check.py --selftest
python3 psi_kernel_check.py -n 1 "e5e1 - 3e4e2 + 3e3e3 - e2e4"
python3 psi_kernel_check.py -n 2 --omega 5 7 1
python3 psi_kernel_check.py -n 1 "e3e_{-1} - 4e2e0 + 6e1e1 - 4e0e2 + e_{-1}e3"
```

Input: a sum of `coefficient word` terms; words are letters `e<i>` side by side
(`e5e1`, `e3*e3`, `e_{-1}e3`). Coefficients may be fractions (`-4/3`).

In VS Code: open this folder, then Run and Debug (F5) and pick one of the configurations in
`.vscode/launch.json`; edit its `args` to test other elements.

## research/

Scripts used to explore and cross-check the results numerically (exact arithmetic mod a large prime):

- `witt_kernel.py` — computes ker Psi_1 on U(W_{>=1}) weight by weight and finds minimal generators.
- `check418.py` — checks the dimension counts behind Pham–Timmins' Proposition 4.18 (W_{>=-1}).
- `psi2plus.py` — the same exploration for Psi_2 on U(W_{>=1}) (generator Omega^(5)_{7,1}).
- `check_clean.py`, `check_interp.py` — checks of the bracket identities and the interpolation step (d).

Run them from inside `research/`, e.g. `python3 witt_kernel.py 2147483629 14`.
